AV Atelier Premium
- First-use onboarding asks for a name and theme color.
- Color theme can be changed in Settings.
- Tasks persist in localStorage on the current device/browser.
- Includes task categories, priority, notes, edit/delete, and reminder permission.
- Browser notifications are best-effort and may not fire when the app is closed.
- For a Home Screen install, host index.html over HTTPS and use Safari > Share > Add to Home Screen.
- The Save task button updates the current stored schedule; it does not create duplicate versions.
